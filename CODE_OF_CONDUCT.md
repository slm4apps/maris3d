# Code of Conduct

We want Maris3D to be a place where anyone can ask questions, report problems and send changes without being harassed.

**Expected:** be respectful and patient; criticise code, results and ideas, not people; assume good faith; give credit.

**Not accepted:** harassment, discrimination, personal attacks, doxxing, sexual or violent language, publishing someone's private
information, or deliberately misleading benchmark claims.

**Scope:** issues, pull requests, discussions and any space where someone represents the project.

**Enforcement:** maintainers may edit or remove content, and warn, mute or ban people who break these rules. Report a problem by
opening a private security advisory on the repository (Security tab) and choosing "conduct" in the title, or by contacting a
maintainer through the contact listed on the repository profile.

This text is a short, original statement in the spirit of widely used community codes; it is not a copy of any of them.
