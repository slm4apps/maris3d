# Recordings and renders of the demo street

Every GIF and video of the Christmas street ([../christmas-street/](../christmas-street/README.md)),
in one place. Free to use under the repository's licence (see [LICENSE](../../LICENSE)).

## Built by the copilot (screen recordings, Blender 5.2, recorded with 0.1, sped up)

Each thing is one typed request. The 204 requests of the demo scenes, replayed through the 0.2 app,
build 188 exactly (right thing, place and size).

## Maris and the things she built

[maris-spin.gif](maris-spin.gif): Maris turns 360 by each thing of the demo street, in a new outfit each time (rendered in
