# Getting help

| You have | Go to |
|---|---|
| A prompt that built the wrong thing | A new issue with the **Failed prompt** form: the sentence, what you expected, what you got |
| An install, server or add-on problem | A new issue with the **Bug report** form. Run `maris3d doctor` first and paste its output |
| A question about how to phrase a request | [docs/PROMPTING-GUIDE.md](docs/PROMPTING-GUIDE.md), then the Discussions tab |
| An idea | The **Feature idea** form, or Discussions |
| Results from your machine | The **Result report** form |
| A security problem | [SECURITY.md](SECURITY.md): do not open a public issue |

Before you ask: [docs/FAQ.md](docs/FAQ.md), [docs/USAGE.md](docs/USAGE.md),
[docs/SAFETY-AND-LIMITATIONS.md](docs/SAFETY-AND-LIMITATIONS.md).

This is a small project run in spare time. Issues are read; an answer can take a few days.
